# Minimalist Dev Portfolio

A high-performance, mobile-first personal portfolio built with a focus on "Hardware-as-Software" aesthetics—merging tactile physical design principles with modern web technologies.

## 🚀 Tech Stack

- **Framework**: Next.js 16+ (Turbopack)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion v12
- **Language**: TypeScript
- **Icons**: Lucide React
- **Design System**: Custom system based on Material Design 3 tokens

## ✨ Key Features

- **Hardware-as-Software Aesthetic**: A design philosophy that ensures every interaction feels as tactile and responsive as a physical device.
- **Premium Micro-animations**: Staggered entrances, smooth layout transitions, and high-performance tactile feedback using Framer Motion.
- **Advanced Glassmorphism**: Custom utilities for subtle backdrop blurs, translucent borders, and depth effects.
- **Production-Ready Architecture**: Optimized for zero-error builds, strict type safety, and fast load times.
- **Mobile-First Design**: Fully responsive layouts spanning from 375px to 1440px+.

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install
```

### Development

```bash
# Start the development server
npm run dev
```

### Production

```bash
# Build the optimized production application
npm run build

# Start the production server
npm start
```

## 🎨 Design System

The project follows a strict minimalist design system documented in `design-system.md`, focusing on:
- **Typography**: Inter (Modern, Sans-serif)
- **Color Palette**: Neutral surfaces with curated high-contrast secondary accents.
- **Elevations**: Subtle shadows and glassmorphic layers instead of heavy gradients.
